A Razer Synapse
alternative for Mac.

Synapse for Mac exists now — but it's Apple Silicon only, and its supported-device list leaves plenty of mice out. MacRazer talks to the mouse directly over USB HID, so the model on Razer's "unsupported" list still gets battery, DPI, RGB, polling rate and button remaps.

Download for macOS All features

Unofficial project. MacRazer is not affiliated with, authorized by, or endorsed by Razer Inc. It's a community app that reimplements the parts of the protocol documented by OpenRazer.

Where each one fits

Both are worth having. If Synapse for Mac supports your device and you want macros and cloud profiles, use it. This page is for the case it doesn't cover.

What MacRazer actually does

01 · battery

Battery in the menu bar

Live percentage with a bolt while charging, a learned time-until-empty estimate built from your own mouse's discharge history, and a warning once it drops below 15%. More on battery →

02 · dpi

DPI and polling rate

Set DPI, edit the stage table your mouse's own DPI button cycles, and switch polling rate between 125/500/1000 Hz. Written to onboard memory, so it survives quitting the app.

03 · lighting

RGB without Chroma

Static colour, spectrum cycle, wave, or off, plus brightness — no Chroma runtime and no background service.

04 · remap

Side-button remapping

Map the two side buttons to keys or shortcuts. Software-side, so it needs Accessibility permission — and it's honest that the other buttons are handled onboard and invisible to macOS.

Common questions

Does Razer Synapse work on Mac?

Yes — Razer ships Synapse for Mac, on Apple Silicon only, with a published supported-device list. Check that list first. If your mouse is on it and you want macros, use Synapse.

My mouse isn't on Razer's list. Now what?

That's the gap this app was built for — the Cobra HyperSpeed and Atheris weren't covered, which is why MacRazer exists. The protocol is largely shared across models, so an unsupported-by-Synapse mouse usually still answers. See supported mice for what's actually been verified on hardware.

Do I need a kernel extension or a driver?

No. macOS already enumerates the mouse as a HID device; MacRazer sends feature reports to it. You do have to grant Input Monitoring, because macOS gates HID access behind it.

Will it work over Bluetooth?

No, and no app can. Razer only exposes the control protocol over USB — use the 2.4 GHz dongle or a USB-C cable. Over Bluetooth the mouse is just a pointer.
